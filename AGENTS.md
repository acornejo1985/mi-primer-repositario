# Instrucciones del repositorio

Todas las operaciones de Git se realizan siempre sobre el repositorio de esta carpeta (`C:\Users\acornejo\Desktop\IAGenerativa\Clase06_Ejercicio28`).

- **«subí los cambios»** (también «subi los cambios»): agregar los archivos modificados al área de preparación (`git add`), hacer un commit con un mensaje que explique qué cambió y, después, ejecutar `git push`.
- **«bajá los cambios»** (también «baja los cambios»): ejecutar `git pull`.
- **«guardá una versión»** (también «guarda una versión»): hacer solo un commit (con un mensaje que explique qué cambió), sin hacer `push`.
