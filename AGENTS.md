# Instrucciones del repositorio

Todas las operaciones de Git se realizan siempre sobre el repositorio de esta carpeta.

- **"subi los cambios"**: agregar los archivos modificados al área de preparación (`git add`), hacer un commit con un mensaje que explique qué cambió y, después, ejecutar `git push`.
- **"baja los cambios"**: ejecutar `git pull`.
- **"guarda una versión"**: hacer solo un commit (con un mensaje que explique qué cambió), sin hacer `push`.
